# PocketSmart AI – SmartBridge Submission

This repository is organized according to the eight SmartBridge project phases.

1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

See `source-code/` for the runnable implementation and each phase folder for submission material.

## Before GitHub Submission
- Add your team members' names.
- Add your college/faculty details if required.
- Add screenshots from your actual running application.
- Run the test cases and record actual results.
- Upload the demo video to Google Drive and set access to Anyone with the link.
- Create a public GitHub repository and upload this complete folder.
