# Phase 8 – Project Demonstration Script

## 1. Introduction
“Good morning/afternoon. Our project is **PocketSmart AI – Your Smart Budget & Recommendation Assistant**.”

## 2. Purpose
“The purpose of PocketSmart AI is to help users plan different lifestyle needs within a defined budget and receive personalized recommendations.”

## 3. Benefits
“The system reduces manual comparison and provides structured suggestions for home interiors, party planning and jewelry selection.”

## 4. Working Process
“First, the user registers and logs in. Then the user selects a planner and enters the required budget and preferences. The FastAPI backend validates the request and sends it to the recommendation layer. Gemini can process the request when configured. If AI is unavailable, the fallback recommendation engine provides demo recommendations. The result is saved in recommendation history.”

## 5. Demo Order
1. Open the application.
2. Open `/docs`.
3. Register a user.
4. Login and copy the JWT token.
5. Authorize the API.
6. Demonstrate `/generate-home`.
7. Demonstrate `/generate-party`.
8. Demonstrate `/generate-jewelry`.
9. Demonstrate `/history`.
10. Show the final recommendation output.

## 6. Closing
“This project demonstrates how generative AI and web technologies can be combined to provide budget-aware, personalized recommendations.”
