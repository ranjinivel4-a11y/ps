# Phase 7 – Project Documentation

## Abstract
PocketSmart AI is a smart budget and recommendation assistant designed to help users plan lifestyle needs across home interiors, parties and jewelry. It accepts budget and preference information and generates recommendations through an AI layer with a fallback engine.

## Objectives
- Simplify budget planning
- Generate personalized recommendations
- Support multiple lifestyle domains
- Provide optional image-aware jewelry recommendations
- Store recommendation history

## Technology Stack
- Python
- FastAPI
- SQLAlchemy
- SQLite
- JWT
- HTML/CSS/JavaScript
- Gemini API integration

## Conclusion
PocketSmart AI combines a web backend, recommendation logic and generative AI concepts into a single budget-aware assistant. It is designed as a modular project that can be extended with approved live product/service APIs.
